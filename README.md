# 🍔 Khao Ji Khao — Food Ordering Website

A responsive food ordering web app built with vanilla HTML, CSS, and JavaScript. No frameworks, no libraries — just pure frontend fundamentals.

---

## 🚀 Latest Update

🔐 **Login & Sign Up Authentication Page Added**

- Responsive Login Popup  
- Modern Sign Up Form  
- Smooth Toggle Between Login / Register  
- Better User Experience  
- Clean UI Design  

---

## 🚀 Live Features

- 🛒 **Add to Cart** — Add items, increase/decrease quantity, auto-remove at 0  
- 💰 **Real-time Total** — Cart total and item count updates instantly  
- 📦 **Dynamic Menu** — Products loaded from `products.json` (no hardcoding)  
- 📱 **Responsive Design** — Mobile hamburger menu, works on all screen sizes  
- 🎠 **Review Carousel** — Swiper.js powered testimonial slider  
- 🔒 **Duplicate Prevention** — Same item can't be added twice  
- 🔐 **Login & Sign Up Page** — Frontend authentication UI added

## 📁 Project Structure

```
khao-ji-khao/
├── index.html       # Main HTML file
├── style.css        # All styling

└── images/          # All assets
```

## 💡 What I Learned

- Fetching and rendering data dynamically from a JSON file
- Managing cart state using JavaScript arrays without any framework
- Real-time DOM updates for quantity and price calculation
- Building responsive layouts with Flexbox and media queries

---

## 🔧 How to Run

1. Clone the repo
2. Open `index.html` in your browser
3. Make sure `products.json` is served via a local server (e.g. VS Code Live Server) — direct file open will block the fetch request
